# md-reader 产品概览

## 概述

`md-reader` 是面向本地项目的 Markdown 阅读与编辑工作区。它以 Markdown 文件为唯一正文真相，在不把内容迁移到专有富文本格式的前提下，提供接近现代文档工具的文件树、标签页、标题导航、阅读预览和可视编辑体验。

## 产品定位

- 运行形态：本地 Node.js 服务与浏览器前端。
- 主要用户：维护项目 Markdown 文档的开发者、设计者和 AI agent。
- 核心场景：接入一个本地项目，浏览 Markdown 文件树，阅读长文档，在可视编辑或源码分栏中修改内容，并让改动安全地写回原文件。

## 当前能力

- 注册、切换本机项目，并扫描其中的 `.md` 与 `.mdx` 文件。
- 通过文件树浏览、收藏、隐藏、拖拽排序和文件操作管理文档。
- 通过顶部标签页同时打开多个文档、切换活动文档与恢复会话。
- 提供常规工作区：锁定时用于最终阅读预览，解锁后进入可视 Markdown 编辑。
- 提供分栏工作区：左侧精确编辑 Markdown 源码，右侧查看最终预览。
- 从 Markdown 标题生成大纲，并支持标题导航与折叠状态。
- 支持主题、字体大小、页面宽度和行间距等个人阅读偏好。
- 对 Mermaid fenced code block 在最终预览中渲染图表。
- 以自动保存为默认交互，在离开编辑上下文前刷新待保存内容，并在保存失败时阻断切换。

## 产品不做什么

- 不替代通用笔记平台、在线协作系统或源码 IDE。
- 不把 Markdown 正文转换为 block JSON、专有富文本数据库或云端文档。
- 不提供多人实时协作、版本控制或自动合并；这些职责仍属于文件系统和 Git。
- 不保证所有 Markdown、HTML 或嵌入内容都能在可视编辑中结构化修改。

## 推荐理解方式

将产品分成三层理解：

1. **项目与文件层**：本地服务登记项目并安全扫描、读取、写入 Markdown 文件。
2. **工作区与偏好层**：文件树、标签页、标题导航和个人界面状态决定如何组织阅读。
3. **内容与保存层**：Markdown 是正文真相；不同模式决定展示与编辑方式，自动保存负责将内容安全写回。
