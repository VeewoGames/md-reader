# 快速开始

## 前提

- Node.js `22.13.0` 或更高版本。
- 一个包含 Markdown 文件的本地目录。
- Windows、macOS 或 Linux 上可访问本机回环地址的浏览器。

## 安装依赖

在仓库根目录执行：

```powershell
npm install
```

## 启动工作区

```powershell
npm run open
```

命令会启动或复用本地服务，并输出浏览器入口。默认地址为 `http://127.0.0.1:8797/`。

## 检查服务

```powershell
npm run health
```

成功时会返回 JSON，包含 `ok: true`、`mode: "local-service"`、实际端口和已加载项目数量。也可以直接访问 `http://127.0.0.1:8797/api/health`。

## 接入第一个项目

1. 在浏览器打开 `npm run open` 输出的地址。
2. 在顶部栏选择连接项目的入口，并选择包含 Markdown 的本地目录。
3. 项目会显示在“项目切换”列表中；首次注册的项目会成为当前项目。
4. 在左侧文件树选择一个 Markdown 文档开始阅读。

默认会扫描项目根目录中的 `.md` 和 `.mdx` 文件，并跳过 `.git`、`node_modules`、`.md-reader`。

## 第一次编辑

1. 在常规模式打开文档。
2. 点击“解锁”进入可视编辑；或者切换到“分栏”，在左侧修改 Markdown 源码。
3. 输入后等待自动保存完成。顶部栏会显示“正在保存”“已保存”或“保存失败”。
4. 切换文档、切换模式或锁定常规模式前，应用会主动刷新当前待保存内容。

如保存失败，请留在当前文档，先处理错误提示再继续操作；应用不会静默丢弃待保存修改。

## 停止服务

```powershell
npm run stop
```

## 常用开发命令

```powershell
npm run build
npm run lint
npm test
```

这些命令分别用于构建、静态检查和测试；普通使用者不需要在每次编辑时执行它们。
