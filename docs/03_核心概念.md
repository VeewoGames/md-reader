# 核心概念

## Markdown-first

Markdown 正文是 `md-reader` 的唯一内容真相。阅读、可视编辑和分栏源码编辑都围绕同一份 `.md` 文件工作，保存结果仍是原生 Markdown，而不是应用私有格式。

## 项目

项目是一个本地目录。服务为其生成稳定的项目 ID，记录根路径、访问方式和内容根目录。当前注册入口默认将项目根目录 `.` 作为内容根目录。

## 文档与路径

文档是内容根目录内的 Markdown 文件。前端使用相对于项目根目录的正斜杠路径，例如 `docs/README.md`。服务拒绝绝对路径与 `..` 目录穿越，确保读写不会越出允许的内容根。

## 工作区

工作区由文件树、文档主区和标题导航组成。顶部栏负责项目、Profile、标签页和模式切换；主区负责当前文档的阅读或编辑。

## 常规与分栏

- **常规**：锁定状态是最终阅读预览；解锁后进入可视 Markdown 编辑。
- **分栏**：左侧是完整 Markdown 源码编辑区，右侧是与常规锁定状态一致的最终预览。

详细职责见 [05_Markdown与三模式机制.md](./05_Markdown与三模式机制.md)。

## Profile

Profile 是个人工作区偏好的容器。它保存主题、字体大小、页面宽度、行间距、侧栏尺寸、文件树展开状态、标题折叠状态、隐藏项、收藏项和手动排序等信息。Profile 不改变 Markdown 正文。

## 会话

会话记录当前打开的标签页、活动文档、模式、滚动位置和阅读进度。刷新页面或重新打开工作区时，应用会尝试恢复这些状态；若文件已在外部删除，会清理失效标签并回退到可用文档。

## 最终预览

最终预览是锁定常规模式和分栏右侧的共同阅读表面。它负责将 Markdown 转成阅读结果，并为 Mermaid 等预览专属内容提供图形化显示。
