# 工作区与交互

## 界面结构

工作区主要由三部分组成：

1. **顶部栏**：连接或切换项目、切换 Profile、管理标签页、选择常规或分栏模式、解锁常规编辑、查看保存状态和调整阅读偏好。
2. **左侧文件树**：展示 Markdown 文件与目录，承担打开、收藏、隐藏、排序和文件操作。
3. **中间文档区与右侧大纲**：文档区用于阅读或编辑；大纲根据标题定位内容并维护折叠状态。

## 项目列表管理

顶部项目下拉底部的“管理项目…”打开管理面板。右侧加号与面板中的“添加项目”共用路径输入对话框，接入已有目录；新项目追加末尾，重复接入不重复添加、不改变原位置。添加后打开项目前仍需处理未保存文档；取消切换时项目保留在列表中。

管理面板显示名称、完整路径和当前项目。拖动手柄或使用上下移按钮调整顺序，松手或点击后自动保存；普通项目切换不会重排列表。排列按当前个人配置保存在本机，刷新、服务重启后恢复。

“移除”只从当前个人配置的列表注销登记，保留磁盘目录、Markdown、项目配置和历史阅读状态。移除当前项目时先处理未保存内容，再准备列表中的下一项；没有下一项则准备上一项。准备或保存失败时不移除。移除最后一个项目后保留当前 Profile，并显示可再次添加项目的空状态。

列表修改结果未知时，界面暂停后续清单修改并提供“重试确认项目列表”，草稿仍归原项目。跨项目提交的短暂阶段会暂时禁止正文输入，防止新输入被工作区提交覆盖。若其他窗口已修改清单，当前操作会提示冲突，需确认后重试；不实时同步其他窗口的工作区。

## 文件树

文件树默认确保根目录和当前文档的祖先目录可见。当前实现支持：

- 打开文件和在多标签间切换。
- 创建、重命名、复制、移动和删除文档；创建目录。
- 收藏文档和按收藏过滤。
- 隐藏文档或目录，并通过“显示隐藏项”恢复查看。
- 拖拽调整文件或目录的排列与层级。

删除操作不可恢复；在确认删除前请先确认该文件没有未提交的 Git 价值。

## 标签页

每个已打开文档对应一个标签页。可以切换、关闭和拖拽重排标签页；会话恢复会尽量保留其顺序与活动标签。若某个标签关联的文件被外部删除，恢复期间会自动清理它。

右上角“阅读选项”中的“未固定标签上限”可设为 1–30，默认 10，按当前项目和 Profile 保存。新打开文档达到上限时，应用优先保留当前标签，按打开先后关闭最早且可安全关闭的未固定标签。拖拽和切换不改变打开先后；未保存、正在保存、保存失败或冲突的标签会保留。如果安全候选不足，应用保留现有标签并提示先处理，新的标签不会打开。

鼠标悬停标签时，左侧立即出现图钉；点击可固定或取消固定。固定标签不计入上限，不会被自动关闭；图钉在固定后持续显示，刷新后仍保留固定状态。固定标签仍可手动关闭，关闭后重新打开不再固定。键盘聚焦时也可操作图钉，不支持悬停的触屏设备会直接显示图钉。

调低上限或取消固定不会立即关闭现有标签，即使恢复的会话已超额也会先保留；下次打开新标签时再尝试关闭足够数量的安全候选。

## 标题导航

应用从当前 Markdown 内容中提取标题。点击大纲项可定位到对应标题；展开与折叠状态属于 Profile 偏好，不写入 Markdown。

## 文档内链接与分享

在常规锁定预览和分栏右侧预览中，项目内 `.md` / `.mdx` 链接会在当前工作区打开目标文档。切换前会先保存当前未保存内容；若保存失败，应用会留在当前文档。

地址栏和“复制链接”使用可恢复的分享地址，其中包含项目、Profile、文档路径；链接也可以附带标题定位。刷新或在新标签打开这类地址会恢复同一文档。Ctrl/Cmd/Shift/中键点击保留浏览器的新标签行为。

只接受当前项目内容根内、并且存在于文件树中的内部文档目标。无效、越界或不存在的链接会在应用内提示，不会打开裸 `.md` 地址。当前版本不会自动改写文档重命名或移动后的其他文档引用。

## 阅读偏好

顶部栏提供以下个人选项：

- 主题：浅色、深色或跟随系统。
- 默认字体大小：`14` 至 `18`。
- 页面宽度：窄、宽、全宽。
- 正文行间距。
- 未固定标签上限。

这些偏好按当前项目的 Profile 保存，不会修改 Markdown 正文。

## 安全操作习惯

- 大规模重排或删除前，先在 Git 中检查工作区改动。
- 使用分栏左侧进行需要精确控制的 Markdown、表格、frontmatter、原始 HTML 或代码块修改。
- 顶部显示“保存失败”时不要继续切走，先确保问题已经解决。
