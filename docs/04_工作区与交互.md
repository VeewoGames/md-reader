# 工作区与交互

## 界面结构

工作区主要由三部分组成：

1. **顶部栏**：连接或切换项目、切换 Profile、管理标签页、选择常规或分栏模式、解锁常规编辑、查看保存状态和调整阅读偏好。
2. **左侧文件树**：展示 Markdown 文件与目录，承担打开、收藏、隐藏、排序和文件操作。
3. **中间文档区与右侧大纲**：文档区用于阅读或编辑；大纲根据标题定位内容并维护折叠状态。

## 文件树

文件树默认确保根目录和当前文档的祖先目录可见。当前实现支持：

- 打开文件和在多标签间切换。
- 创建、重命名、复制、移动和删除文档；创建目录。
- 收藏文档和按收藏过滤。
- 隐藏文档或目录，并通过“显示隐藏项”恢复查看。
- 拖拽调整文件或目录的排列与层级。

删除操作不可恢复；在确认删除前请先确认该文件没有未提交的 Git 价值。

## 标签页

每个已打开文档对应一个标签页。可以切换、关闭和拖拽重排标签页；会话恢复会尽量保留其顺序与活动标签。若某个标签关联的文件被外部删除，恢复期间会自动清理它。

## 标题导航

应用从当前 Markdown 内容中提取标题。点击大纲项可定位到对应标题；展开与折叠状态属于 Profile 偏好，不写入 Markdown。

## 文档内链接与分享

在常规锁定预览和分栏右侧预览中，项目内 `.md` / `.mdx` 链接会在当前工作区打开目标文档。切换前会先保存当前未保存内容；若保存失败，应用会留在当前文档。

地址栏和“复制链接”使用可恢复的分享地址，其中包含项目、Profile、文档路径；链接也可以附带标题定位。刷新或在新标签打开这类地址会恢复同一文档。Ctrl/Cmd/Shift/中键点击保留浏览器的新标签行为。

只接受当前项目内容根内、并且存在于文件树中的内部文档目标。无效、越界或不存在的链接会在应用内提示，不会打开裸 `.md` 地址。当前版本不会自动改写文档重命名或移动后的其他文档引用。

## 阅读偏好

顶部栏提供以下个人选项：

- 主题：浅色、深色或跟随系统。
- 默认字体大小：`14` 至 `18`。
- 页面宽度：窄、宽、全宽。
- 正文行间距。

这些配置只影响当前 Profile 的显示，不会修改项目文件。

## 安全操作习惯

- 大规模重排或删除前，先在 Git 中检查工作区改动。
- 使用分栏左侧进行需要精确控制的 Markdown、表格、frontmatter、原始 HTML 或代码块修改。
- 顶部显示“保存失败”时不要继续切走，先确保问题已经解决。
