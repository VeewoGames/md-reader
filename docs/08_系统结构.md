# 系统结构

## 总体结构

```text
浏览器前端（React + TypeScript）
  ├─ App：项目、会话、保存与模式编排
  ├─ app：顶部栏、三栏工作区、交互控件
  ├─ workspace：文件树、Profile、会话、Provider 与本地服务访问
  ├─ editor：可视 Markdown 编辑器
  ├─ document-renderer：只读渲染与 Mermaid
  └─ markdown：展示层 Markdown 变换与标题提取
          │ HTTP
本地 Bridge（Node.js）
  ├─ bridge-server：路由和服务生命周期
  ├─ project-registry：本机项目注册表
  ├─ project-scanner / reader / writer：扫描、读取与带冲突保护的写入
  ├─ project-node-operations：文件与目录操作
  └─ project-profiles：项目级 Profile 持久化
          │
本地项目 Markdown 文件与 %APPDATA%/md-reader 注册表
```

## 前端职责

- `src/App.tsx`：应用状态总协调，包括项目加载、文档切换、会话恢复、自动保存、错误处理与服务调用。
- `src/app/`：顶部栏、工作区布局、文件树交互、大纲和对话框。
- `src/workspace/`：项目与文件树模型、浏览器/本地服务 Provider、Profile 与会话状态。
- `src/editor/`：Milkdown/Crepe 可视编辑器及编辑结构事件。
- `src/document-renderer/`：最终只读预览和 Mermaid 图表。
- `src/markdown/`：标题解析与共享展示变换。

## 服务端职责

- `server/bridge-server.mjs`：HTTP 路由、静态 Web UI 和服务停止/重启。
- `server/project-registry.mjs`：项目注册表、项目 ID 和活动项目。
- `server/project-scanner.mjs`：Markdown 文件树扫描。
- `server/project-reader.mjs`：受内容根约束的读取与路径校验。
- `server/project-writer.mjs`：带修改时间/哈希检查的写入。
- `server/project-node-operations.mjs`：创建、复制、移动、重命名、删除等节点操作。

## 数据落点

- Markdown 正文：用户项目中的 `.md` / `.mdx` 文件。
- 本机项目注册：`%APPDATA%/md-reader/projects.json`。
- 项目 Profile：`<项目根目录>/.md-reader/profiles.json`。
- 浏览器侧降级状态：浏览器存储；仅作为非服务可用时的 fallback。

## 测试结构

- `tests/app/`：应用、工作区、保存、标签页和阅读偏好。
- `tests/workspace/`：文件树、会话、Profile、注册与本地服务访问。
- `tests/server/`：HTTP 服务、注册、扫描、读取、写入和节点操作。
- `tests/editor/`：可视编辑器与编辑能力边界。
- `tests/document-renderer/`：最终预览和 Mermaid。
- `tests/markdown/`：Markdown 变换与标题提取。

文档改动通常只需要检查链接与 Markdown 格式；涉及实现或协议时，应运行相应定向测试，并至少执行 `npm run build`。
