# md-reader 文档索引

## 概述

这套文档说明 `md-reader` 已经实现且值得长期维护的产品能力、使用方式和机制边界。目标读者是希望快速开始阅读或编辑 Markdown 的使用者，以及需要维护或扩展产品的开发者与 AI agent。

历史需求、实施计划和讨论记录保留在 [方案](./方案/)；它们用于追溯设计过程，不替代本索引下的正式产品说明。
