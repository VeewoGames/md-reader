# 增加收藏文件夹功能：需求确认记录

## 背景与目标

现有 `md-reader` 仅支持收藏 Markdown 文档。用户希望把收藏能力扩展到真实文件夹，使一个受关注的内容分组能通过收藏视图整体访问，同时不改变磁盘中的实际目录结构。

本轮目标是：让文件与目录都可被收藏，并让收藏目录在“只看收藏”视图中作为其可见内容子树的入口。

## 已确认需求

1. 收藏对象扩展为文档和真实目录节点；不新增仅汇总文档的虚拟收藏目录。
2. 收藏状态仍属于当前项目、当前 Profile 的长期导航偏好。
3. 开启“只看收藏”时：
   - 已收藏文档直接显示；
   - 已收藏目录显示该目录及其完整可见子树；子文件无需逐一收藏；
   - 同一节点在树中只出现一次，嵌套收藏不产生重复分支。
4. 收藏不能突破隐藏规则：
   - 默认隐藏内容不进入收藏视图；
   - 开启“显示隐藏项”后，收藏目录内的隐藏内容可以出现，并继续使用隐藏弱化样式。
5. 目录收藏的交互与文档收藏一致：
   - 目录行提供常显星标，点击可收藏或取消收藏；
   - 目录右键菜单提供“收藏/取消收藏目录”；
   - “只看收藏”仍是文件树过滤态，不创建或移动真实目录。
6. 路径变更规则：
   - 本轮不新增目录改名、移动或删除能力；
   - 若用户在应用外改名、移动或删除目录，后续扫描发现收藏路径已不存在时，需清理陈旧记录；
   - 未来目录文件管理功能应另行定义“收藏路径自动跟随”的规则，不在本轮承诺。
7. 收藏过滤要继续与既有导航规则协作：隐藏可见性派生在前，收藏过滤在中，文本搜索在后；过滤态不可修改手动排序。

## 明确不做

1. 不创建名为“收藏”的物理文件夹，也不写入用户 Markdown 项目。
2. 不把收藏目录复制或镜像成第二套文件树。
3. 不允许收藏绕过隐藏规则。
4. 不在本轮改变收藏的 Profile 作用域或把“只看收藏”持久化为跨会话状态。

## 开放问题

无。实现细节由方案文档在不违背上述规则的前提下确定。

## 验收标准

1. 用户能从目录行星标和右键菜单收藏、取消收藏目录。
2. 收藏视图能展示收藏文档以及收藏目录的完整可见子树，且无重复节点。
3. 隐藏项只有在“显示隐藏项”开启时才出现在收藏结果中，并保留弱化状态。
4. 外部目录变更后的刷新不会保留失效或指向旧路径的收藏数据。
5. Profile 切换、文件树刷新、搜索与手动排序继续满足原有行为边界。

## 需求决策依据

- 用户已确认目录收藏表示对整个内容分组的关注，因此收藏视图显示完整子树。
- 用户已确认收藏不应暴露隐藏内容；本轮外部路径变更后通过刷新清理失效收藏，不承诺自动跟随。
- 现有收藏、隐藏、搜索和排序均已位于导航投影层；本轮延续这一职责边界。
