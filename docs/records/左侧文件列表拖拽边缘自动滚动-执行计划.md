# 方案概述：左侧文件列表拖拽边缘自动滚动执行计划

## 1. 总体目标和范围

落实已确认方案：在左侧文件树有效拖拽期间，根据指针在 `.panel__content--tree` 上下边缘的位置连续滚动列表；滚动后重新解析指针下的落点，保持高亮与最终拖放目标正确。

范围限定为 `WorkspaceSidebarPane` 的文件树交互和定向测试，不修改顺序持久化、真实文件移动、过滤态规则或视觉样式。

## 2. 各阶段任务概要

1. 建立边缘滚动计算与测试基线。
2. 接入拖拽会话、帧调度和滚动后落点重算。
3. 补齐组件测试并完成浏览器验收。

## 3. 整体结构框架

```text
纯计算 helper
  └─ 边缘方向 / 强度 / 每帧增量
      └─ WorkspaceSidebarPane 拖拽状态
          └─ requestAnimationFrame 滚动与边界停止
              └─ 指针坐标重新命中
                  └─ 复用现有落点解析与 drop 处理
```

## 4. 执行任务

### 阶段一：抽取计算边界

1. 在与 `WorkspaceLayout` 职责相邻的最小位置新增边缘滚动纯 helper，输入容器矩形、`clientY` 和触发带宽，输出方向与归一化强度/滚动增量。
2. 将触发带定义为上、下各约 48px；中间区域输出停止；靠近边缘的速度单调增加并有上限。
3. 为 helper 新增定向单元测试：上/下边缘、临界点、中间安全区、强度单调性和极值。

完成条件：计算无浏览器副作用，可被独立测试，且未涉及文件树业务状态。

### 阶段二：接入文件树拖拽生命周期

1. 在 `.panel__content--tree` 使用捕获阶段的 `onDragOverCapture`（或等价 native capture listener）保存最新 `clientX` / `clientY` 并计算边缘意图；只在 `dragNodePathRef.current` 存在时允许启动调度。该监听不调用 `preventDefault()` 或 `stopPropagation()`，因此不干扰行级与尾部既有的落点处理；捕获阶段也能在行级处理器已停止冒泡时持续收到事件，并覆盖面板边缘空白区域。
2. 使用 `requestAnimationFrame` 按最近意图更新 `fileTreePanelRef.current.scrollTop`，而不是依赖 `dragover` 频率。
3. 将现有依赖 `React.DragEvent.currentTarget` 的行内排序位置计算拆为可由命中元素矩形、保存坐标和节点类型复用的纯计算；既有事件处理器与滚动后重命中均调用该同一入口，避免形成两套落点规则。
4. 每次实际滚动后，以保存的 `clientX` / `clientY` 重新命中当前行或列表尾部，调用上述统一计算与已有同父级排序/目录拖入解析，刷新 `reorderDropTarget` / `dropDirectoryPath`。
5. 在离开触发带、达到上/下滚动尽头、`dragend`、成功 `drop` 和组件卸载时取消帧循环并清空边缘意图。
6. 保持 `onReorderFileTreeNode()` 和 `onMoveDocument()` 的输入与职责不变；只将 `resolveRowReorderPositionWithCenterBand()` 重构为统一可复用的计算入口。

完成条件：自动滚动只改变文件树容器的可视区域和当前落点状态，绝不扩大排序/移动语义。

### 阶段三：验证与回归

1. 扩展 `tests/app/workspace-layout.test.tsx`：覆盖向上/向下滚动、离开边缘、`dragend`、成功 `drop` 和滚动尽头的停止行为；并验证捕获阶段记录在既有行级 `stopPropagation()` 后仍可触发，且不影响行级落点处理。
2. 新增“指针停在边缘、列表滚动后不再移动”的测试：高亮和最终 drop 目标须更新到当前指针下的新行或尾部。
3. 运行新增测试和相关既有文件树测试；执行项目既有构建/测试命令中与本改动相称的校验。
4. 在真实浏览器启动项目，以超过一屏的文件树手动验证上、下边缘滚动、不可见目标可达、停止条件、落点正确性，以及搜索态/只看收藏态不被扩张。

完成条件：自动化测试通过；浏览器手测有明确结果。若环境不具备浏览器或长列表数据，必须如实报告该验收未执行，不以静态测试替代。

## 5. 回归边界

- 同父级排序的 before/after/tail 目标解析。
- 文件拖入目录的中心命中和目录高亮。
- 搜索态、只看收藏态的排序禁用。
- 拖拽结束后状态清理。
- 滚动容器已在顶端或底端时不发生空转。
