# 方案概述：最近 50 条与当前文档定位

## 1. 总体目标和范围

将「最近」从全项目文档清单收敛为最多 50 条的高性能快捷入口，消除大项目中切换文档时左侧列表的大规模同步重绘。同时保持顶部标签页作为完整的工作上下文：任何已打开文档都不因其是否进入最近 50 条而被隐藏、关闭或改变顺序。

当用户从顶部标签页切换到一篇不在最近 50 条中的文档时，最近列表不变动、不插入该文档；左侧明确提示当前文档未包含在最近列表内，并提供一次性「在目录中定位」入口。点击后退出最近模式，回到普通目录树并展开该文档所在目录。

本方案只处理最近列表的数量、定位反馈和渲染成本；不改变文档时间计算、隐藏规则、收藏规则、标签页持久化或文档保存协议。

## 2. 各阶段任务概要

### 阶段一：固定最近投影上限

- 在现有严格隐藏投影和时间排序后，仅保留前 50 个文件节点。
- 排序仍为 `recentAtMs` 降序，同一时间按规范化路径升序；隐藏文件、隐藏目录及其后代仍不得参与候选集。
- 预期成果：最近模式最多渲染 50 个双行文件项，项目文件总数不再决定单次文档切换时的左侧 DOM 数量。

### 阶段二：当前文档不在最近列表时的反馈与定位

- 由 `App` 先根据当前文档路径、`hiddenPaths` 与现有 `isPathExplicitlyHidden` / `isPathHiddenByAncestor` 判定隐藏态；仅在未隐藏且仍存在于严格可见树时，再根据截断后的最近 50 条计算 `isCurrentDocumentOutsideRecent`。
- 最近模式且当前文件存在但排在 50 条之外时，在左侧列表顶部、搜索栏下方显示非阻塞提示：`当前文档不在最近 50 项中`，并提供「在目录中定位」按钮。
- 点击定位：关闭 `showRecentOnly`，保留当前标签和正文；将当前文件的祖先目录加入 `expandedFileNodes`，复用已有导航持久化路径。目录树提交后由现有 `currentDocumentPath` 高亮当前文件。
- 隐藏文件显示：`当前文件已隐藏，未显示在最近列表中`，不提供定位按钮。
- 当前文件不在严格可见树且并非隐藏时显示：`当前文件已不存在或不可访问`，不提供定位按钮。
- 预期成果：列表不会为追随当前文件而跳动，用户仍有一步返回完整上下文的明确出口，也不会将第 51 条或已删除文件错误标记为隐藏。

### 阶段三：渲染边界与回归验证

- 保持顶部标签页始终传递完整 `session.tabs`；禁止以最近 50 条反向过滤标签页。
- 为最近投影加上限单元测试；为提示、定位、标签完整性和隐藏规则补充组件/状态测试。
- 在大项目快照（数千文件）下确认最近模式 DOM 项数不超过 50，标签切换不触发列表条目数量膨胀。
- 预期成果：性能修复不损害未保存标签、标签拖放、收藏、隐藏或普通目录树定位。

## 3. 整体结构框架

```text
项目树快照 + 隐藏规则
        ↓
严格可见文件树
        ↓
按 recentAtMs 排序的扁平文件列表
        ↓
take(50) ───────────────→ 最近侧栏（最多 50 项）
        │                         │
        │                         ├─ 当前文件在列表中：现有高亮
        │                         └─ 当前文件不在列表中：提示 + 在目录中定位
        ↓
完整 session.tabs ──────────────→ 顶部标签页（永不按最近 50 条过滤）
```

## 4. 产品行为定义

| 场景 | 左侧最近列表 | 顶部标签页 | 用户可见结果 |
| --- | --- | --- | --- |
| 最近模式下点击最近 50 条中的文件 | 保持排序与内容，高亮该项 | 激活/新增对应标签 | 正常切换 |
| 从顶部切到最近 50 条中的标签 | 保持排序与内容，高亮该项 | 激活该标签 | 正常切换 |
| 从顶部切到不在最近 50 条的标签 | 保持原 50 项，不插入当前文件 | 激活该标签 | 显示定位提示 |
| 点击「在目录中定位」 | 退出最近模式，显示完整目录树 | 标签不变 | 展开祖先目录并高亮当前文件 |
| 当前文件被隐藏 | 最近列表不显示 | 已打开标签不被关闭 | 不提供绕过隐藏规则的定位入口；提示文案改为“当前文件已隐藏” |
| 当前文件已删除或不可访问 | 最近列表不显示 | 已打开标签保留，以便用户决定如何处理 | 显示“当前文件已不存在或不可访问”，不提供定位 |
| 关闭最近模式 | 恢复普通树或收藏模式既有行为 | 标签不变 | 无额外副作用 |

### 4.1 不动态插入当前文件

不得在用户切换顶部标签时把当前文件临时塞入最近 50 条。这会导致第 50 项被挤出、列表内容和滚动位置频繁跳动，也会让“最近”同时承担历史排序和当前定位两种相互冲突的职责。

### 4.2 顶部标签页不受截断影响

`session.tabs` 是用户的工作集，可能包含未保存内容、滚动位置和拖拽排序。最近 50 条只是导航投影，不能作为标签页可见性条件。两者必须保持单向关系：标签页可以激活任意文档；最近列表只对其中符合条件的文档显示高亮。

## 5. 实现设计

### 5.1 `src/workspace/file-tree.ts`

为 `collectRecentFileTreeNodes()` 添加可选 `limit`，默认保持当前完整投影行为，最近视图调用时传入常量 `RECENT_DOCUMENT_LIMIT = 50`。先完成现有排序，再 `slice(0, limit)`，确保边界项稳定。

### 5.2 `src/App.tsx`

- 定义 `RECENT_DOCUMENT_LIMIT = 50`。
- 生成两个 memo 值：`recentFileNodes`（严格隐藏、排序、截断后的文件）和当前文档在严格可见树中的存在性。
- 以 `currentDocumentPath`、`new Set(hiddenPaths)`、`isPathExplicitlyHidden` 与 `isPathHiddenByAncestor` 计算 `isCurrentDocumentHiddenInRecent`；该判断必须先于“是否位于最近 50 条”。
- 仅当当前文件未隐藏、仍存在于严格可见树、且未包含在 `recentFileNodes` 时，令 `isCurrentDocumentOutsideRecent` 为真。
- `visibleFileTree` 在最近模式直接返回 `recentFileNodes`；普通与收藏模式保持现有分支。
- 新增 `handleLocateCurrentDocumentInTree()`：
  1. 读取 `currentDocumentPath`；不存在则无操作。
  2. 关闭最近模式。
  3. 计算祖先目录路径，合并到 `expandedFileNodes`。
  4. 必须调用现有 `handleExpandedFileNodesChange()` 完成状态更新与持久化；不得只修改 `WorkspaceSidebarPane` 内部的 `expandedDirectories`。
- 将定位状态与回调通过 `AppShell` 传至 `WorkspaceLayout`。

定位不需要重新请求项目树、不需要重读当前文档，也不改动 `session`。

### 5.3 `src/app/AppShell.tsx` 与 `src/app/WorkspaceLayout.tsx`

- 增加只读 props：`isCurrentDocumentOutsideRecent`、`isCurrentDocumentHiddenInRecent`、`isCurrentDocumentUnavailableInRecent`；增加回调 `onLocateCurrentDocumentInTree`。
- `WorkspaceSidebarPane` 在 `showRecentOnly` 时渲染提示区域。该区域不进入文件树 `ul`，避免影响键盘列表语义和拖放边界。
- 正常情形显示：`当前文件不在最近 50 项中` + 「在目录中定位」。
- 隐藏情形显示：`当前文件已隐藏，未显示在最近列表中`，不提供定位按钮。
- 不可用情形显示：`当前文件已不存在或不可访问`，不提供定位按钮。
- 提示使用 `role="status"`，按钮使用明确的 `aria-label="在目录中定位当前文件"`。

### 5.4 性能边界

50 条上限是本轮主策略，足以将 5760 文档项目的最近列表 DOM 从数千项收敛到固定上限。无需在本轮引入虚拟列表库：这会新增滚动测量、可访问性、拖放及测试复杂度，和当前“最近快捷入口”需求不成比例。

后续若 50 条双行项目仍出现明显卡顿，再单独评估：

1. 对文件行做细粒度 memo，只更新旧/新当前项；
2. 将搜索过滤移至 memo；
3. 在需求增长到数百条时再引入虚拟滚动。

## 6. 测试与验收

### 自动化测试

- 70 条可见文档：最近投影恰为 50 条，且第 50 条排序正确。
- 时间相同：路径升序稳定；创建时间不可用的回退行为不变。
- 隐藏文档或隐藏祖先目录：即使其时间最新，也不占用 50 条名额。
- 已打开但不在最近 50 条的文档：顶部标签仍存在且可激活；左侧显示提示，不显示该文件行。
- 点击定位：最近模式关闭、当前标签不变、祖先目录展开、当前文件高亮。
- 当前文件隐藏：提示存在、定位按钮不存在。
- 当前文件已被外部删除或不可访问：显示不可用提示，且不误提示为隐藏。
- 最近/收藏互斥、标签重排、未保存文档和 Profile 切换回归通过。

### 手工验收

1. 在至少 100 个 Markdown 文档的项目打开最近模式，确认左侧不超过 50 项。
2. 从顶部切换到第 51 条之外的已打开文档，确认列表不跳动、标签不消失、提示出现。
3. 点击定位，确认立即回到目录树并定位当前文件。
4. 多次在 50 条内外切换标签，确认文档内容、滚动位置与未保存草稿不丢失。
5. 使用键盘 Tab 与读屏检查提示和按钮语义。

## 7. 非目标与风险控制

- 不截断或过滤顶部标签页。
- 不因为当前选中文档而重写最近排序。
- 不让隐藏文件通过定位动作泄露到普通树。
- 不重扫磁盘、不修改项目树快照、不改变保存协议。
- 不在本轮引入虚拟滚动；固定 50 条先解决主性能问题并保持维护成本低。
